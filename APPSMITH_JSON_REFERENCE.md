## Dynamic Binding Patterns

The generated `Text1` uses a text binding registered in `dynamicBindingPathList`:

```json
{
  "type": "TEXT_WIDGET",
  "text": "Hello {{appsmith.user.name || appsmith.user.email}}",
  "dynamicBindingPathList": [
    { "key": "text" }
  ]
}
```

Generated layout widgets place theme expressions in `dynamicBindingPathList`. For example, `Container1` contains:

```json
{
  "type": "CONTAINER_WIDGET",
  "borderRadius": "{{appsmith.theme.borderRadius.appBorderRadius}}",
  "dynamicBindingPathList": [
    { "key": "borderRadius" },
    { "key": "boxShadow" }
  ]
}
```

`dynamicPropertyPathList` is not present in the generated `Text1` or `Container1` excerpts above. The generated reference should be consulted for the exact widget/property combination rather than applying a generic list.

## Rules for Copilot

1. Never invent Appsmith widget JSON keys.
2. Use Appsmith-generated JSON as the schema reference.
3. Copy verified dynamic metadata patterns only for the same widget type and property.
4. Do not place a property in `dynamicPropertyPathList` unless Appsmith itself generates it there for that widget/property.
5. Appsmith SQL must not contain a trailing semicolon.
6. Validate exported JSON before commit.
7. Test the actual Appsmith runtime before accepting a page.
